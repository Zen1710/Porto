Before writing any code, I answered the questions that would be expensive to change later, one at a time, and wrote the answers down in the repo.

## Who it is for

Recruiters and hiring managers. That single answer decided most of the rest: English only, a short page, and a contact form plus a CV always within reach.

## Choices I made

| Question | Decision | Why |
| --- | --- | --- |
| Framework | Next.js + Tailwind CSS v4 | The React framework most full-stack roles ask for |
| Hosting | Vercel Hobby | Server Actions work with no adapter |
| Content | MDX files in the repo | Free, versioned, and adding a post is adding a file |
| Spam | Honeypot + time trap + validation | No extra service until spam actually shows up |

The reasoning for the bigger decisions lives in `docs/adr/`.
