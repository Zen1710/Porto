## What it is

My final year project in Informatics Engineering at Universitas Bengkulu: detecting whiteflies (Aleyrodidae), a pest of cucurbit crops, with YOLOv11. The model runs entirely in the browser, so images never leave the device and there is no inference server to host.

## Features

- Detect live from a webcam, using the rear camera on phones
- Detect from an uploaded image
- Recognize whiteflies and five host plants: melon, cucumber, bottle gourd, ridged gourd, and bitter gourd
- See the total detections, average confidence, and the count per class
- Get an infestation risk category based on the number of detections, from very low to critical

## How it is built

I trained a YOLO11n model with Ultralytics on a dataset annotated in Roboflow, with 2,824 training images and 339 validation images at 640 × 640. The model is exported to TensorFlow.js and served as static files from GitHub Pages. The web app is plain HTML, CSS, and JavaScript with no build step, and runs inference on the WASM backend. The exported model has no non-max suppression yet, so overlapping boxes can inflate the detection count.
