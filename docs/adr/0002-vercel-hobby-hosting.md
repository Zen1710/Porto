# Hosting di Vercel Hobby

Situs di-deploy ke Vercel Hobby (gratis). Situs referensi (wahyusyahputra.com) di-hosting di Cloudflare, dan Cloudflare Workers + OpenNext juga gratis. Kita tetap memilih Vercel karena Next.js, termasuk Server Action untuk form kontak, langsung jalan di sana tanpa adapter. Di Cloudflare, paket gratisnya membatasi ukuran Worker sampai 3 MiB, dan dukungan OpenNext untuk Next.js 16 belum jelas. Paket Hobby hanya untuk pemakaian personal non-komersial, dan itu cocok karena situs ini portfolio, bukan tempat jualan.
